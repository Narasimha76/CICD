Project on Continuous Integration and Continuous Deployment (CI/CD) Pipeline

The Objectives of this project includes 📈 :

✅ We Set up a version control system using Git.

✅ Created a Jenkins pipeline for building and testing the web application.

✅ Containerized the application with Docker.

✅ Configured an AWS CodePipeline to automate the deployment process.

✅ Deployed the application to AWS ECS or EKS using AWS CodeDeploy.

✅ Monitors deployments and rollback in case of issues.
